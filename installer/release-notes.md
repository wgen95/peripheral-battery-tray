推荐下载 `PeripheralBattery-1.1.1-Setup-x64.exe`，双击安装。自带 .NET 运行时，无需管理员权限。

- 添加开始菜单入口，可选桌面快捷方式，在 Windows“已安装的应用”中直接卸载。
- 浮层设备名称仅显示 `A950`、`S75`，面板缩小到 180×68 逻辑像素。
- 卸载前正常退出进程，并清理程序文件、快捷方式、自启动项、配置、日志及本应用的 .NET 解包缓存。
- 实测覆盖安装、运行中卸载和残留检查；校验其他应用的相邻目录不受影响。
- 保留免安装 ZIP 供需要的用户选择；提供 SHA256SUMS.txt。

真实硬件读取与 v1.0.0 相同：A950 / 260D:1074 已验证 50%，S75 / 0C45:FEFA 已验证 57%、56%。这些是测试时设备报告值，运行时按设备实际数据更新。断连 / 失败时不显示旧百分比。
