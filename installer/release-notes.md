v1.4.0：可切换配色，默认黑白，白色消耗弧居下。

- 设置新增“托盘配色”：黑白（默认）、青绿 / 白、蓝 / 白、绿 / 白、紫 / 白、橙 / 白，保存后立即生效并记住选择。旧配置升级后默认使用黑白。
- 剩余电量弧以正上方为中心，白色已消耗部分以正下方（6 点钟）为中心对称变化，不再偏到右侧。
- 低电量仍按用户的阈值将对应环变红；无有效电量时保持灰色虚线。内外环设备切换保留。
- 硬件查询、键盘闲置保护和电量浮层不变。只更新图标，沿用原来的通知区域 GUID。
- 后续发行仅提供安装程序及校验文件；本机应用验证通过覆盖安装完成，不再直接运行便携副本。

安装、覆盖升级及干净卸载由 CI 在独立环境验证。安装程序自带 .NET，无需管理员权限，尚未代码签名。
