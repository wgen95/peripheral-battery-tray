v1.3.0：双环电量托盘。推荐下载 `PeripheralBattery-1.3.0-Setup-x64.exe`，由用户自行安装测试。

- 默认外环为 S75 键盘、内环为 A950 鼠标；设置新增“内外环设备”，可以对调并保存，保存后立即生效。
- 从 12 点起顺时针显示剩余电量：正常为青绿色、已消耗部分为白色。达到用户设置的低电量阈值时，只将对应环变红；0% 保留细红边作为低电量提示。
- 无有效读数时使用灰色虚线环，不把闲置、断连或读取失败伪装为 0% / 100%，不沿用旧百分比。
- 本次功能变更限于托盘显示及其设置；原有浮层、HID 查询、键盘闲置保护、安装 / 卸载流程不变。更新图标沿用同一个 HWND / GUID。
- 新增不启动应用、不注册托盘、不访问硬件的绘制测试，覆盖映射、阈值、状态、配置兼容、不同尺寸及图标资源释放；预览图使用明确标注的演示数据。

安装程序自带 .NET，不需要管理员权限。安装包尚未代码签名。真实桌面上的图标观感和设备状态切换，由用户安装后测试。
