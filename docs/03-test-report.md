# 测试与验收 · 2026-10-24

环境：实际 Windows 11 x64，系统版本 10.0.26200.0，.NET SDK 8.0.426。本机屏幕 150% DPI。不是跨平台生成后未经运行的项目。

## 真实硬件结果

| 项目 | 实际结果 |
|---|---|
| A950 / 260D:1074 | Python hidapi 与 C# 原生 HID 两条实现均收到有效 17 字节报告，50%，校验和通过 |
| 260D:1084 | 单独查询得到有效 50% 报告；物理型号与同一鼠标的接口关系未确认，因此不默认选它 |
| S75 | FF60 查询返回内部身份 0C45:8006 / 2:15，电量先 57%、随后 56%；对应官网 S75 标准版配置 |
| 无线端不可用 | 捕获 S75 的 `55 FC 04`，官方定义为无线断连通知；程序显示设备断连并清除百分比 |
| 恢复 | 用户按键 / 移动设备后，C# 再次读到 A950 50% / S75 57%；这是无线查询恢复测试，不是拔插接收器测试 |
| 自包含发布版 | 未依赖全局 .NET 8 Runtime，exe 可启动；`--diagnose` 返回 0，产生真实设备 JSON |

源报告与本机完整 HID 路径保存在本地 `evidence/`，不公开提交。协议文档保留不含唯一设备标识的帧样例。没有把演示百分比当真实数据，没有把参考 PR 的测试当成本机测试。

- 41 条协议 / 状态断言通过。涵盖真实采样帧、有效边界、坏头、命令、ACK、长度、校验和、S75 内部身份与超范围电量，以及失败状态不展示历史百分比。这些构造的无效帧是测试夹具，不是硬件成功证据。

- `Shell_NotifyIconGetRect` 成功找到系统注册的通知区域图标。
- 在测试程序中触发托盘左键和菜单事件，验证开关面板、保持后台图标、诊断关闭后的刷新。事件由测试程序触发，未将它表述为手动鼠标验收。
- 使用 Windows computer-use 技能检查了实际诊断与设置控件的可访问性树和读数。另用 WinForms DrawToBitmap 检查渲染图片，修正 150% DPI 下浮层文字截断；最终为 330×108 物理像素，即 220×72 逻辑尺寸。
- 发布版重复启动、打开诊断、正常退出和子查询结束均做进程级检查。发现并修复退出时重复 Dispose 的问题。
- 自启动默认关闭；未通过实际重启 Windows 测试登录启动。

## 资源与运行范围

自包含 exe 约 68.35 MiB，压缩包约 63.22 MiB（最终文档变化可能造成小幅差异）。框架附带的运行时增加文件体积。

短时后台实测：主进程约 113–117 MiB 工作集；约 32 秒样本中 CPU 累计增加 0.1875 秒，包含首次查询后的初始化。不能把这段短样本当长期稳定性或长期平均 CPU 保证。每次轮询另有短命查询进程，内存峰值会更高。默认每 60 秒一次，浮层隐藏时无鼠标轮询计时器。
