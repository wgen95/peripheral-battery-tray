# v2.1 改进说明

保留双环、六种配色、黑白默认及底部白色消耗弧。设备名称继续只显示 A950、S75，没有新增服务、浏览器或常驻 .NET 界面。

## 直接从托盘操作

右键菜单增加“托盘配色”和“内外环设备”，直接保存并应用选择，不必启动设置窗口。已有设置 / 诊断窗口再次从菜单打开时会恢复并移到前面。悬停图标期间保持浮层，拖动时仍收起浮层。

## 低电量提醒

设置增加“低电量时提醒”。本次运行中，有效电量达到阈值时，每个设备每轮低电量提醒一次，采用 Windows 无声通知。持续低电量、休眠、断连或读取失败不会反复提醒；有效电量恢复到阈值以上 5 个百分点后，才允许下一轮提醒。重启应用后重新判断。通知遵从系统设置，不能保证在专注或关闭通知时显示。

## 查询与恢复

- Raw Input 只取设备头信息，核对 S75 接收器身份；不读取按键值。其他键盘的输入不会恢复 S75 自动查询。无法确认匹配时保持暂停，仍可用“立即刷新”主动查询。
- 接收器拔出时，即使键盘闲置，也能从已枚举接口识别断连，不向键盘发送请求。
- 更换设置中的接收器时作废旧读数与旧查询，再按新的选择读取，避免展示上一个接收器的百分比。
- Explorer 暂不可用或通知图标注册失败时自动重试；恢复正常后停止重试计时器。
- USB 接口在枚举过程中消失时跳过失效接口；设置保存或诊断导出失败时保留窗口并提示原因。

设备电量协议保持不变，不写灯光、休眠、复位或其他设备设置。悬停 / 查看电量不会主动查询；独立命令 `--diagnose` 也不主动唤醒闲置 S75，诊断窗口的“刷新”属于主动查询。

## 验证

纯协议、接收器选择、配置兼容与原生策略测试使用合成数据，不注册托盘或读取硬件。真实应用验证从安装包覆盖升级，保留原设置与安装位置；不运行便携副本。完整卸载在 GitHub Actions 的独立干净用户环境测试，不卸载用户当前安装。

本机 308 项自动检查通过，v2.0 → v2.1 覆盖安装保持原配置。105 秒采样的常驻工作集中位数 11.29 MiB、私有内存 2.38 MiB，查询期间观察到的合计工作集峰值 69.79 MiB。详细条件见 [内存报告](06-memory.md)，测试范围及未完成的实机场景见 [测试报告](03-test-report.md)。

原生 API 依据：[Raw Input 设备头](https://learn.microsoft.com/windows/win32/api/winuser/nf-winuser-getrawinputdata)、[设备接口名称](https://learn.microsoft.com/windows/win32/api/winuser/nf-winuser-getrawinputdeviceinfow)、[通知图标与无声提醒](https://learn.microsoft.com/windows/win32/api/shellapi/ns-shellapi-notifyicondataw)。
