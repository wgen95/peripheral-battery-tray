# 故障排查

1. **图标看不到**：打开任务栏 `^` 收纳区；双击 exe 也会通知当前实例。关闭浮层不会退出程序，正常退出请使用右键菜单或 `--quit`。
2. **设备断连**：如果接收器还在但 S75 返回 `55 FC 04`，只表示无线端断连。请按键、检查 2.4GHz 档位后刷新。程序不会用旧百分比填补空白。
3. **接收器断连**：确认 USB 接收器在本机；在诊断 HID 列表检查 VID/PID。更换端口可能改变 USB 父接口，设置中重新选择或改为自动。
4. **读取失败**：打开诊断，查看时间、原始响应和具体错误。权限 / 共享错误可能是厂商软件占用，不要求强制关闭它；可自行选择在它退出后再比较。A950 无回复的原因尚未确定，不能直接断言休眠。
5. **暂不支持**：当前只适配上述实测固件。标准版和 Pro、Air、Wing 的名称相近不代表协议相同。不要随意发送私有命令或修改 VID/PID 骗过身份校验。
6. **不知道选哪个接收器**：A950 默认唯一的 1074；S75 默认唯一的 FF60 接口。多个相同接收器时程序拒绝猜测，设置可指定。USB 父接口和 HID 路径在诊断中可见。
7. **启动失败**：Release 为 Windows x64；ARM64、32 位与 Windows 10 尚未实机验证。查看 `%LOCALAPPDATA%/PeripheralBattery/app.log`；从源码运行需 .NET 8 Desktop Runtime，Release 自带它。
8. **看起来没更新**：默认 60 秒查询，相同读数不会导致窗口闪烁。右键立即刷新。设备报告本身可能量化 / 缓存，软件不能保证化学电量的精确度。
9. **自启动位置变了**：移动 exe 后，在新位置打开设置重新保存开机启动。安装版请使用 Windows 应用列表中的卸载入口，会清理程序、自启动、配置、日志和运行时缓存。免安装 ZIP 版手动删除 exe 不会自动清理用户数据。

后续协议扩展应先确认内部设备身份、报告长度、命令语义、响应校验及真实对照，再新增 IBatteryProvider。不要把随意读取的字节转换为百分比。导出诊断用于反馈前检查其中本机路径和标识。
