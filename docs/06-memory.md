# v2.0 低内存常驻

常驻托盘和双行浮层采用 C++ / Win32 / GDI+，保留原通知图标 GUID、双环设备切换、六种配色、黑白默认、白色消耗弧居下及低电量变红。常驻进程不加载 CLR、WinForms，不启动浏览器、服务或驱动。

原有经过实机验证的 .NET HID 查询保持不变，按轮询周期启动短命进程，完成即退出；8 秒看门狗限制卡住的查询。原有设置和诊断窗口在需要时启动独立进程，关窗即退出。父进程使用 Job Object 管理子进程寿命，正常退出先关闭界面，父进程意外结束时也不会遗留后台组件。键盘仍仅在键盘活动窗口内查询，闲置时不唤醒设备；无有效电量不显示旧百分比。

## 实机测量，2026-10-25

同一台 Windows 11 x64；从注册安装目录覆盖升级并运行，不直接运行便携副本。没有使用 EmptyWorkingSet、工作集上限或定时 GC 来制造低数字。

| 场景 | 常驻工作集 | 常驻私有内存 | 主进程和查询组件的合计工作集采样峰值 |
|---|---:|---:|---:|
| v1.4.0，升级前后台单次样本 | 88.7 MiB | 57.7 MiB | 未采集 |
| v2.0.0，冷启动，75 秒样本中位数 | 11.29 MiB | 2.18 MiB | 63.54 MiB |
| v2.0.0，设置 / 诊断关窗后，105 秒样本中位数 | 16.93 MiB | 3.29 MiB | 69.66 MiB |

105 秒样本覆盖用户当前 90 秒轮询周期，观察到一次查询子进程，结束时没有遗留后台组件；常驻进程模块中没有 coreclr.dll。常驻工作集范围为 16.88–16.95 MiB，相比旧版单次样本减少约 81%。

测量使用 100 ms 等待间隔，另有进程枚举和采集开销；比采样间隔更短的尖峰可能漏采。工作集包含可共享页，私有内存为私有提交量，不能混为一个数；任务管理器具体列也可能使用不同口径。打开设置 / 诊断时会加载其 .NET UI 进程，该阶段内存高于表中关闭界面的常驻值。短样本不等于数日长期保证。

复验命令：`./tools/measure-installed-memory.ps1 -Seconds 105`。需要先通过安装程序安装当前版本。原生绘制 / JSON 自检不会注册托盘或访问硬件；真实应用测试使用安装目录中的程序。
